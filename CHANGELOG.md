# Changelog

All notable changes are documented here. Versions follow SemVer; pre-release
versions (a/b/rc) must never be presented as stable.

## 0.1.0a1 (unreleased)

- Initial scanner: `audit_text` / `audit_prompt` detect FORBIDDEN-class
  invisible characters (ZERO_WIDTH, BIDI, TAG_BLOCK, SURROGATE_ORPHAN,
  CONTROL) with exact source offsets and three preset policies
  (strict / balanced / neutral).
- Homoglyph tables (policy version 2, extended by version 3):
  - `HOMOGLYPH_UN` — 1,730 mixed-script confusables parsed from Unicode
    `confusables.txt` 18.0.0 (UTS #39), filtered to single-codepoint sources
    with a single ASCII-printable target; ASCII sources and blocks reserved
    for other categories (CJK, fullwidth) excluded by rule. Unicode License
    v3 (Data Files and Software) shipped in `licenses/`.
  - `HOMOGLYPH_CJK` — hand-curated 形近字 table, 250 groups / 650 characters,
    MIT, with a documented frequency guard (top-frequency characters such as
    日/人/大 are deliberately not flagged).
  - Both flag SUSPICIOUS/REVIEW under every preset; custom policies may
    promote them to FORBIDDEN/REMOVE. Findings carry `confusable_with`
    evidence (e.g. Cyrillic `с` → `c`, `己` → `已/巳`).
- INFO classes (policy version 3):
  - `FULLWIDTH_HALF` — fullwidth ASCII alphanumerics and halfwidth katakana
    (NFKC-normalizable), runtime ranges, no data table.
  - `PUNCT_VARIANT` — the only context-dependent category: the scanner flags
    punctuation of the minority script of each string (ASCII `", "` inside
    Chinese text, fullwidth `，！` inside ASCII text); `classify()` stays
    context-free, single-script text produces no punctuation noise.
  - `SOFT_HYPHEN` (SUSPICIOUS) — U+00AD plus LRM/RLM, Arabic letter mark,
    and deprecated format characters.
- `audit_corpus`: streaming auditor over any iterable of strings, one
  `Report` per input at constant memory; the policy is validated eagerly at
  call time.
- `sanitize`: delete-only removal with a ChangeLog whose offsets point back
  into the original text; UTF-16 round-trip stability verification for
  policies that flag lone surrogates (byte-boundary recombination guard).
  Homoglyphs and INFO classes are kept by `strict` (delete-only cannot
  substitute the look-alike) and removable via custom policy.
- `diff_visible`: opcode-level comparison that attributes each difference to
  a hidden or visible cause, with a Chinese `explain()` report. Homoglyphs
  count as visible characters (they are visible; the new "易混淆字符" line
  itemizes them), so `equal_visible` semantics are unchanged for invisible
  characters. Common prefix/suffix are trimmed before difflib runs: a
  near-identical 100k-char pair went from a measured 85.6s to 0.168s with
  identical segment semantics (benchmarks/RESULTS.md).
- Shipped data tables embed `_meta` provenance (source URL, version, raw
  SHA-256, filter rule, per-stage counts, canonical-map SHA-256) and are
  fingerprinted via `charaudit.TABLE_FINGERPRINTS`, asserted by tests.
- Known-vector tests (promptfoo zero-width payload, Trojan Source bidi,
  Unicode tag block, lone surrogate, ANSI/C1 controls, Cyrillic/Greek/CJK
  homoglyph vectors, soft hyphen, fullwidth/halfwidth, punctuation mixing,
  corpus streaming semantics), offset-invariant fuzz tests, sanitize
  reconstruction fuzz, diff reconstruction fuzz, and long-input boundary
  tests — 85 tests.
- Reproducible benchmarks (`benchmarks/run_bench.py`, seeded synthetic
  samples) with measured results and the diff_visible before/after
  comparison in `benchmarks/RESULTS.md`; demo artifact generated by real
  runs (`scripts/make_demo.py` → `docs/assets/demo.txt`); bilingual README,
  ROADMAP, SECURITY, CONTRIBUTING, REPORT.
- Not yet implemented: Unicode additions beyond the listed SOFT_HYPHEN
  ranges (tracked as data-table updates); ASCII lookalikes (1/l, 0/O) as a
  possible future INFO class.
